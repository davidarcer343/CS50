## Regla de oro

Todo dato lleva fuente y nivel de confianza:
- 🟢 **Verificado**: varias fuentes independientes coinciden.
- 🟡 **Declarado**: lo dice la empresa o su fundador (no auditado).
- 🔴 **Inferido**: estimación nuestra, con el cálculo explícito.
